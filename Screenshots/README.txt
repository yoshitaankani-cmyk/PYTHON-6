# String-Based Examination Answer Evaluation

## About the Project
The String-Based Examination Answer Evaluation system is a Python program that evaluates multiple-choice examination answers by comparing student responses with a predefined answer key.

## Objectives
- Accept the correct answer key.
- Accept student responses.
- Count correct and incorrect answers.
- Identify unanswered questions.
- Calculate the final examination score.

## Concepts Used
- Variables and data types
- Strings
- String indexing
- For loop
- Conditional statements
- Arithmetic operators

## How the Program Works
1. The correct answer key is entered.
2. The student's answers are entered.
3. The program checks whether both strings have equal lengths.
4. Each answer is compared with the corresponding answer key.
5. Correct, incorrect, and unanswered responses are counted.
6. The final score is calculated using positive and negative marking.
7. The examination result is displayed.

## Conclusion
This project demonstrates how Python string operations, loops, and conditional statements can be used to evaluate examination answers automatically.
